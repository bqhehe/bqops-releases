# Bqops 安装包发布

Bqops（终端 + 网络运维平台）各版本的安装包发布与更新日志。

- 主下载源（推荐，国内直连）：https://dl.bqops.com/
- 官网：https://www.bqops.com/
- 反馈与联系：bqsmartops@163.com

## 下载

| 平台 | 文件 |
|---|---|
| Windows x64 | `bqops-<版本>-setup-x64.exe` |
| macOS Apple Silicon | `bqops-<版本>-macos-arm64.dmg` |
| macOS Intel | `bqops-<版本>-macos-x64.dmg` |
| Linux | `bqops-<版本>-linux-amd64.deb` / `.AppImage` |

各版本资产见右侧 Releases 页面；macOS/Linux 更新清单为 `rc-mac.yml` / `rc-linux.yml`（预发布通道）。
